# 🐳 Run Backend with Docker

## 📦 Prerequisites

- Docker installed
- Docker Compose installed

---

## 🚀 Start application

```bash
docker compose up
```

---

## ▶️ Run in background

```bash
docker compose up -d
```

---

## 🛑 Stop application
```bash
docker compose down
```

---

## 🔄 Rebuild after code changes
```bash
docker compose up --build
```

---

## 📜 View logs
```bash
docker compose logs -f
```

---

## 🌐 Access application
```bash
http://localhost:8080
```
